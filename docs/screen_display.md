# MaixCam 相机屏幕显示说明

相机屏幕分为三层：**状态文字**（左上角）、**图形叠加**（画面中）、**触摸按钮**（底部）。

---

## 1. 状态文字（左上角 4 行）

```
S:CAPTURE_TARGET T:- DIR:UNKNOWN
LINE:LOST
V L:0/0.0 R:0/0.0
EVT:NONE TX:-
```

### 第 1 行 — 状态 / 目标 / 方向

| 字段 | 含义 | 可能的值 |
|------|------|---------|
| `S:` | 状态机当前状态 | `CAPTURE_TARGET`（识别目标）、`WAIT_START`（等待发车）、`FOLLOW_LINE`（循线中）、`WAIT_TURN_DONE`（等待转弯完成） |
| `T:` | 锁定的目标房号 | `1`~`8`，`-` 表示未锁定 |
| `DIR:` | 上一次发出的转向方向 | `LEFT`（左转）、`RIGHT`（右转）、`UNKNOWN`（尚未决策） |

### 第 2 行 — 巡线状态

| 字段 | 含义 | 可能的值 |
|------|------|---------|
| `LINE:` | 黑线检测状态 | `OK`（正常追踪）、`LOST`（丢线，画面中未找到黑线） |

### 第 3 行 — 方向投票器

| 字段 | 含义 |
|------|------|
| `V` | 方向投票器（Voter），仅目标 3~8 时有效 |
| `L:3/6.5` | 左转：3 帧投票 / 累计置信度 6.5 |
| `R:1/0.8` | 右转：1 帧投票 / 累计置信度 0.8 |

**工作原理**：数字出现在道路中心左侧时投左转，右侧投右转。当某一方向的帧数和累计置信度都超过阈值时，触发方向决策，发送 `TURN_DECISION`。

- 目标 1~2 使用固定路线，不经过投票器，此行的 L/R 始终为 `0/0.0`。

### 第 4 行 — 通信事件

| 字段 | 含义 | 可能的值 |
|------|------|---------|
| `EVT:` | 最近一次 UART **接收**的事件 | `NONE`（尚无）、`RESET`、`START`、`STOP`、`TURN_DONE`、`TARGET_LOCKED`（目标锁定）、`TARGET_LOCKED+DIR`（目标锁定且已发送固定方向，仅 1~2） |
| `TX:` | 最近一次 UART **发出**的消息类型 | `-`（尚无）、`TARGET`(0x81)、`LINE`(0x82)、`TURN`(0x83)、`STATE`(0x85) |

## 2. 图形叠加

### 目标 ROI 框（蓝色矩形）

- **显示条件**：仅在 `CAPTURE_TARGET` 状态下
- **含义**：有效识别区域，数字牌应放在此框内才能被锁定
- 区域范围：画面水平 20%~80%、垂直 10%~90%

### YOLO 检测框 + 数字标签

- **显示条件**：YOLO 运行时（`CAPTURE_TARGET` 或 FOLLOW_LINE 目标 3~8 的 YOLO 帧）
- **含义**：画面中识别到的数字牌，标注房号（`number`）和置信度（`score`）
- **消失时机**：进入 `WAIT_START` 或 `WAIT_TURN_DONE` 后自动清除，不会残留

### 巡线可视化

- **显示条件**：`FOLLOW_LINE` 或 `WAIT_TURN_DONE` 状态下
- 包含以下元素：

| 图形 | 颜色 | 含义 |
|------|------|------|
| 4 个矩形框 | 蓝色 | ROI 采样区域，共 4 段纵向排列，用于定位黑线 |
| 十字标记 | 红色 | 每个 ROI 段内检测到的黑线采样点 |
| 拟合线段 | 绿色 | 由采样点拟合出的完整巡线，从上到下 |
| 偏差线 | 红色 | 线段底端到画面中心 X 的距离，即 `error`（发给小车的 PID 输入） |

## 3. 触摸按钮（底部）

| 按钮 | 颜色 | 功能 |
|------|------|------|
| **RESET** | 橙 | 全局复位：清除目标、停止巡线，回到 `CAPTURE_TARGET` |
| **START** | 绿 | 发车：从 `WAIT_START` 进入 `FOLLOW_LINE`。仅在目标已锁定时有效 |
| **STOP** | 红 | 暂停：回到 `WAIT_START`，保留目标不清除。再按 START 可继续 |
| **TURN_DONE** | 蓝 | 模拟转弯完成：从 `WAIT_TURN_DONE` 回到 `FOLLOW_LINE`，恢复数字识别（调试用） |

---

## 4. 不同阶段的屏幕变化总览

| 阶段 | YOLO 框 | ROI 框 | 巡线图 | L/R 投票 | 说明 |
|------|---------|--------|--------|----------|------|
| 刚上电 | 有 | 蓝框 | 无 | 0/0.0 | 把数字牌放到蓝框内等待锁定 |
| 锁定后（1~2） | 消失 | 消失 | 无 | 0/0.0 | DIR 显示 LEFT/RIGHT，EVT 显示 TARGET_LOCKED+DIR |
| 锁定后（3~8） | 消失 | 消失 | 无 | 0/0.0 | EVT 显示 TARGET_LOCKED，等待发车 |
| 发车后（1~2） | 无 | 无 | 有 | 0/0.0 | 只巡线，不跑 YOLO |
| 发车后（3~8） | 间歇出现 | 无 | 有 | 跳动 | 巡线+YOLO，L/R 投票数据随数字位置变化 |
| 方向发出后 | 消失 | 无 | 有 | 冻结 | 等待小车转弯完成 |
